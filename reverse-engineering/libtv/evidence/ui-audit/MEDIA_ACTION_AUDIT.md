# 媒体结果操作审查

## 范围

图片节点与视频节点的结果预览、下载入口和入口显隐规则。

## 结论

原实现功能可用，但图片与视频分别使用不同的按钮尺寸和样式，图片入口不易发现，视频入口又形成节点专属规则。现已统一为一个媒体下载操作：预览悬停时显示，图片位于预览右下角，视频占用原生控制栏最右侧位置，不存在三点入口或二级菜单。

## 步骤与健康度

1. 全局查看媒体节点：一般。节点密集时不应常驻所有次要操作。
2. 悬停图片预览：良好。显示 40px 下载入口，标签为“下载图片”。
3. 悬停视频预览：良好。显示 46×42px 下载入口，覆盖原三点位置，标签为“下载视频”。
4. 点击下载：代码路径统一。两个入口都触发 `downloadOutput`，由同一下载函数处理当前节点的输出素材。

## 统一规则

- 只有存在图片或视频结果时才渲染下载入口。
- 非悬停状态隐藏，减少多节点画布噪音；键盘聚焦与无悬停设备保持可见。
- 图片、视频使用同一个 `media-download-action` 组件与同一个行为入口。
- 不使用三点菜单，不增加二级操作层。
- 图片和视频分别使用明确的无障碍标签。
